# Contributing

Attendees, presenters, and organizers are welcome to improve this program browser.

## Report a program change

Open a **Program update or correction** issue. Organizers can drag a revised PDF directly into the issue and summarize what changed. Please include the affected day, time, room, session title, and people whenever possible.

## Suggest an enhancement

Open a **Feature request** issue and explain the attendee need first. Ideas that improve mobile use, accessibility, search, or schedule accuracy are especially welcome.

## Submit a code fix

Pull requests are welcome. Keep the site dependency-free and mobile-friendly, preserve keyboard access, and verify `dist/app.js` and `dist/data.js` with `node --check` before opening a pull request.

Program corrections should cite an organizer-provided source. Do not replace names, titles, rooms, or times based only on inference.
